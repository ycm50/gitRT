# 功能速查（面向使用者）

> 这一页是"GitRT 能做什么 + 它到底跑哪条命令"，用来回答"某个操作对应的 git 命令是什么"。
> 面向开发者的结构/约定见 [02-命令表与参数面板](02-命令表与参数面板.md)。

## 1. 右键菜单

默认（`menu.mode = app`）右键里**只有一项「GitRT」**：点它打开主窗口并切到你右键的位置
（`cmdId = 0`）；找不到 git.exe 时这一项改为把用户送进首选项。
`"menu.mode": "tree"` 可切回分层菜单：8 分组 + 可选 `directTop` 直达项 + 可选 `showFlags` 内联开关。
单层最多 16 项（`kMaxItemsPerLevel`），超了自动折叠进「更多…」。

场景裁剪（零 git 调用，纯文件系统探测）：
仓库内目录/空白处 = 全量（隐藏"初始化"）；单个文件 = 只留文件相关命令；
非仓库目录 = 只剩 初始化/克隆/终端/首选项/自检/AI；虚拟项（库、控制面板）= 隐藏；
合并/变基进行中 = 顶部灰显提示项 +`pull/sync/merge/rebase/switch` 灰显。

## 2. 命令 → git 原文

| 命令 key | 界面 | 实际 argv |
| --- | --- | --- |
| `repo.init` | 在此处初始化仓库 | `git init [--initial-branch=<b>]` |
| `repo.clone` | 克隆到此处… | `git clone [--depth=<n>] [--single-branch] [--branch=<b>] [--no-tags] [--filter=<spec>] [--recurse-submodules] <url>` |
| `app.terminal` | 打开终端 | 不起 git，直接 `ShellExecuteW` 启动 git-bash / wt / powershell / cmd；勾"以管理员身份"用 `runas`（UAC） |
| `commit.stage` | 暂存所选内容 | `git add -A [--intent-to-add] -- <paths>` |
| `commit.unstage` | 取消暂存 | `git restore --staged -- <paths>` |
| `commit.discard` | 撤销所选改动【危险】 | `git restore --worktree -- <paths>` |
| `commit.ignore` | 加入 .gitignore | 写 `.gitignore` + 展示 `git check-ignore -v` |
| `commit.commit` | 提交所选内容… | ① `git add -A -- <paths>` ② `git commit [--amend] [--signoff] [--no-verify] -m <msg>` |
| `commit.amend` | 修改上次提交… | `git commit --amend [--signoff] -m <msg>` |
| `commit.undo` | 撤销上次提交（保留改动）【危险】 | `git reset --soft HEAD~1` |
| `commit.squash` | 合并所选提交…【危险】 | 含 HEAD 且非根：`reset --soft <父>`+`commit`；触到根：无父 `commit-tree`+`reset --soft`；不含 HEAD：`commit-tree`+`rebase --onto` |
| `sync.pull` | 拉取 | `git pull [--rebase\|--ff-only] [--prune] [--autostash]` |
| `sync.push` | 推送 | `git push [--set-upstream] [--tags] [--force-with-lease[=<ref>:<expect>]] [--dry-run]` |
| `sync.fetch` | 抓取 | `git fetch [--all] [--prune] [--tags]` |
| `sync.sync` | 同步 | `git pull --rebase --autostash` ; `git push` |
| `branch.switch` / `branch.new` | 切换/新建分支 | `git switch <b>` / `git switch -c <b> [--track=<up>]` |
| `branch.merge` | 合并 | `git merge [--no-ff] [--squash] <b>` |
| `branch.rebase` | 变基【危险】 | `git rebase [--interactive] [--autostash] <b>` |
| `branch.delete` | 删除分支【危险】 | `git branch -d\|-D <b>` |
| `history.restore` | 还原到提交… | `checkout --detach <c>` / `checkout -b <n> <c>` / `reset --soft\|--mixed\|--hard <c>` |
| `tag.list` / `tag.create` / `tag.push` / `tag.delete` | 标签 | `for-each-ref refs/tags` / `git tag [-a] [-f] <n> [-m <m>] [<rev>]` / `git push <r> <n>\|--tags` / `git tag -d <n>`(+ `push <r> :refs/tags/<n>`) |
| `release.list` / `release.create` | GitHub Release | `gh release list` / `gh release create <tag> --title --notes\|--generate-notes [--draft] [--prerelease] [assets…]` |
| `inspect.log` | 提交历史 | 远端基线两段 + `git log --all --graph --decorate --oneline -n 300` |
| `inspect.diff` | 查看差异 | `git diff [--staged] [--stat] [--name-only] -- <paths>` |
| `inspect.filelog` | 文件历史 | `git log --follow --stat -n 100 -- <file>` |
| `inspect.status` | 状态面板 | `git status --porcelain=v2 -z --branch --show-stash` |
| `stash.push` / `stash.pop` | 储藏 | `git stash push [-m <msg>] [--include-untracked] [--keep-index]` / `git stash pop [--index]` |
| `adv.clean` | 清理未跟踪文件【危险】 | 先 `git clean -nd`，确认后 `git clean -f {flags}` |
| `adv.reset` | 重置到…【危险】 | `git reset --soft\|--mixed\|--hard <rev>` |
| `adv.maintenance` | 垃圾回收 | `git gc [--aggressive]` |
| `adv.proxy-set` | 设置代理… | `git config [--global] http.proxy http://127.0.0.1:<端口>` |
| `adv.proxy-unset` | 取消代理设置 | `git config [--global] http.proxy ""` |
| `remote.panel` | 远端分支与地址… | `for-each-ref refs/remotes` / `remote add\|set-url\|remove` / `fetch --prune` / `branch --set-upstream-to` |
| `app.settings` / `app.doctor` / `app.ai` | 首选项 / 自检 / AI 助手 | 不起 git |

## 3. 代理设置（端口号 → 地址）

- 参数只填**端口号**（`10808`），构造期补成 `http://127.0.0.1:10808`；
  `0`/`70000`/`abc`/`10808a`/`http://127.0.0.1:10808` 一律在构造期拒绝。
- 「全局（--global）」默认**勾上**：勾 = 改 `~/.gitconfig`（这台机器所有仓库），不勾 = 只改当前仓库。
- 两条命令都只碰 `http.proxy` —— git 的 **https:// 仓库也读这一个键**（实测：`https.proxy` 不生效）。
- 「取消代理」写空串而不是 `--unset`：空串 = 不走代理且优先于环境变量 `http_proxy`；
  `--unset` 在键不存在时退出码 5，会被面板显示成"执行失败"。

## 4. CLI 门面

```
GitRT.exe --run <command-key> [--param k=v] [--flag k[=v]] [--paths "p1;p2"] [--cwd <dir>] [--dry-run] [--out <file>]
         --list-commands [--out <file>]
         --squash <h1,h2,h3> [--message <m>] [--dry-run]
         --remote-info [--remote-fetch] / --set-upstream <up> / --remote-add name=url / --remote-set-url name=url / --remote-remove <name>
         --restore <hash> --mode detach|branch|soft|mixed|hard [--branch <n>] [--force] [--dry-run]
         --tag-list / --tag-create <n> [--annotated] [--message <m>] [--target <rev>] [--force] [--dry-run]
         --tag-push <n> [--all] [--remote <r>] / --tag-delete <n> [--remote] [--force] [--dry-run]
         --release-list / --release-create <tag> [--title] [--notes] [--generate-notes] [--draft] [--prerelease] [--push-tag] [--asset <f>]…
         --ai "<自然语言>" [--ai-run] [--dry-run]
         --self-test=<file> / --request-section <name> / --request-probe=<file> / --exit-after-request
```

输出是 `key=value` 行（`--out` 写文件时同时尽量写父控制台），脚本据此断言。
`exec=internal` 的命令在 CLI 里**什么都不执行**（exit=1 + 提示），因为它们的形态是窗口。

## 5. 首选项里能改什么

接口地址 / 模型（可从接口拉列表后下拉选，也可手输）/ API Key（明文或 DPAPI 加密）/
超时 / 系统提示词（留空 = 内置默认，旁边有「恢复默认提示词」）/ 自动抓取间隔（分钟，0=关）。
Key 存在 **exe 同目录的 `GitRT.ai.json`**（明文，已在 .gitignore 里）。
「自动抓取」开着时主窗口每 60 秒看一次间隔，到点在工作线程里跑 `git fetch --prune`。
